# Time Tracker Bot v4.0..

Telegram бот для учета времени с графиками статистики и умными напоминаниями.

## 🚀 Основные функции

- **Учет времени** по 6 категориям: Труд, Учёба, Спорт, Хобби, Сон, Отдых
- **Графики активности** в реальном времени
- **Умные напоминания**, привязанные к часам
- **Поддержка часовых поясов** с автоматическим определением
- **Тихий час** - не беспокоить в указанное время
- **Подробная статистика** за день, неделю, месяц и год

## 📊 Новая система статистики

### Графики активности
- Символьные графики за каждый день
- 24 символа = 12 часов (1 символ = 30 минут)
- Разные символы для разных активностей:
  - `▁` - Сон
  - `▂` - Отдых  
  - `▃` - Спорт
  - `▅` - Хобби
  - `▆` - Учёба
  - `▇` - Труд

### Столбчатые диаграммы
- Визуализация распределения времени по активностям
- Автоматическое масштабирование

## ⏰ Умные напоминания

### Особенности:
- Привязаны к часам (12:15, 12:30, 12:45...)
- Кнопки выбора интервала в ответ на уведомление
- Учитывают часовой пояс пользователя
- Учитывают тихое время

### Доступные интервалы:
- 10 минут
- 30 минут  
- 1 час
- 2 часа
- 4 часа
- 8 часов

## 🌍 Часовые пояса

### Автоматическое определение:
- По IP адресу (с кэшированием)
- По локали системы (fallback)
- Ручной выбор из 50+ часовых поясов

### Поддерживаемые регионы:
- Россия (все часовые поясы)
- Украина и Беларусь
- Европа
- Америка
- Азия
- Австралия и Океания
- Африка
- Ближний Восток
